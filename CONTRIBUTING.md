# Contributing

1. Create a branch from the default branch (`docs/...`, `fix/...`).
2. Make small, focused commits following [Conventional Commits](https://www.conventionalcommits.org/), in English
   (e.g. `docs: clarify snapshot save order`).
3. Keep diagrams as code: edit the `.mmd` files in `docs/diagrams/` and update the matching
   Mermaid block in `README.md`.
4. Do not add real data collected from a machine (process names, paths, IP addresses).
